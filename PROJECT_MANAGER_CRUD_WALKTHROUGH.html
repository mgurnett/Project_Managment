2 Category Prefix & Taxonomy
core/models.py
  • Prefix Field: Category.prefix (e.g. 100 for Passives, 200 for Discrete Semiconductors, 300 for Connectors).
  • Recursive Inheritance: get_prefix() checks current category; if empty, ascends parent tree (parent.get_prefix()).
  • Dropdown Display: Category.__str__() formats hierarchies: [100] Passives > Resistors > SMD 0805.
  • Taxonomy Nesting: Self-referential parent = ForeignKey('self') allows unlimited subcategory depth.
Subcategory Inheritance: Defining 100 on Passives allows Resistors and Capacitors to inherit prefix 100 without re-typing.
3 Automated Part Numbering
Prefix Engine
  • Starting Sequence: Sequential numbers start at 1001 (e.g. 100-1001, 100-1002, ..., 100-1234).
  • Dynamic Increment: generate_next_part_number(category) queries existing parts with prefix-*, parses numeric suffixes, and takes max_num + 1.
  • Intelligent Formatting in save():
    • Blank → Auto-generates next available sequence (100-1001).
    • Digits only (e.g. 1234) → Prepends prefix: 100-1234.
    • Custom string → Preserved untouched.
  • Collision Avoidance: Loops candidate numbers until verified unused.
4 Part Documents, Scans, Pinouts & Technical Articles
PartDocument Model
  • Relationship: One-to-Many with Part (part.documents.all()). Multiple attachments per part number.
  • Document Types: datasheet (PDF) • pinout (Diagram/Schematic) • scan (Document Scan) • instructions (Assembly Guide) • article (Technical Notes)
  • File Storage: Uploads to media/parts/documents/%Y/%m/. Auto-detects is_image, is_pdf, and formats file size.
  • External Links: external_url field for manufacturer-hosted online datasheets and web references.
  • WYSIWYG Articles: content = CKEditor5Field() for rich pinout tables, troubleshooting procedures, and markdown notes.
  • Dedicated Viewers: Embedded in-browser PDF reader, high-resolution scan zoom canvas, and print-ready technical article viewer.

5 Sourcing & Location Topology
Ecosystem
  • Company (Supplier): Vendor supplying components (DigiKey, Mouser). Stores account numbers, sales reps, and phone contacts.
  • Manufacturer (OEM): Original brand (Texas Instruments, STMicro).
  • Location: Physical warehouse, rack, or bin code (BIN-A12).
  • Price Automation: price_per × quantity → auto-computes price in model save().
  • Superseding: Self FK superseded_by links legacy parts to newer replacement inventory items.

Operational Phase Action Performed in Interface System Reaction & State Change
1. Category Setup Go to /categories/add/. Enter Name & Prefix (e.g. 100). Prefix stored; inherited by any child subcategories.
2. Part Registration Select category on /parts/add/. Leave part number blank. Auto-generates 100-1001. Computes price = price_per * qty.
3. Suffix Override Enter 1234 in Part Number input. Auto-prepends category prefix to produce 100-1234.
4. Attach Resources On Part detail page, click Add Document / Scan. Uploads PDF/scan, renders thumbnail, and attaches to part record.
5. Document Viewing Click View on any document card. Opens dedicated high-res viewer, embedded PDF, or article body.
