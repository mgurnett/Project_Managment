2 Category Prefix & Taxonomy
core/models.py
  • Prefix Field: Category.prefix (e.g. 100 for Passives, 200 for Compute/RF, 300 for Connectors).
  • Recursive Inheritance: get_prefix() checks current category; if empty, ascends parent tree (parent.get_prefix()).
  • Dropdown Display: Category.__str__() formats hierarchies: [100] Passives > Resistors > SMD 0805.
  • Taxonomy Nesting: Self-referential parent = ForeignKey('self') allows unlimited subcategory depth.
Subcategory Inheritance: Defining 100 on Passives allows Resistors and Capacitors to inherit prefix 100 without re-typing.
3 Automated Part Numbering
Prefix Engine
  • Starting Sequence: Sequential numbers start at 1001 (e.g. 100-1001, 100-1002, ..., 100-1234).
  • Dynamic Increment: generate_next_part_number(category) queries existing parts with prefix-*, parses numeric suffixes, and takes max_num + 1.
  • Intelligent Formatting in save():
    • Blank → Auto-generates next available sequence (100-1001).
    • Digits only (e.g. 1234) → Prepends prefix: 100-1234.
    • Custom string → Preserved untouched.
  • Collision Avoidance: Loops candidate numbers until verified unused.
4 Bill of Materials (BOM) & Product Assembly Architecture
BOM & BOMItem Models
  • Assembly Tracking (BOM): Represents fully assembled products and sub-assemblies (e.g. String, Node, Base Station, Tipups).
  • Assembly Instructions: Integrated CKEditor5Field for WYSIWYG build instructions, test protocols, and revision notes.
  • Real-Time Rollup Metrics:
    • total_items_count: Unique component lines in the build.
    • total_parts_quantity: Total raw physical pieces required.
    • total_cost: Sum of (item.part.price_per * item.quantity).
  • Component Links (BOMItem): Foreign key linking BOM to Part with:
    • quantity: Pieces required per single finished assembly.
    • reference_designator: PCB / schematic designators (e.g. U1, C1-C4, BAR1).
    • notes: Solder, trimming, or torque instructions.
  • Subtotal Calculation: subtotal dynamically returns line cost based on live catalog pricing.

5 ODS Spreadsheet Ingestion Engine (BoMs.ods)
manage.py import_boms
  • Zero-Dependency Parser: Built directly on Python standard library (zipfile + xml.etree.ElementTree) for pure ODS XML parsing.
  • Master Parts List Extraction: Reads Parts list sheet (24 parts), maps suppliers, unit price, quantity, confirmed flag, and external order URLs.
  • DigiKey Component Ingestion: Parses tipups sheet (12 components) creating parts with manufacturers and PCB designators.
  • Automated Revision Superseding:
    • Detects revision series (e.g. 2002.1 → 2002.2).
    • Populates superseded_by Foreign Key relationship automatically.
  • Automated Assembly Construction: Generates assemblies (string, Node, Base_station, tipups) and resolves component references.

6 Datasheets, Scans & Articles
PartDocument
  • Relationship: One-to-Many with Part (part.documents.all()). Multiple attachments per part number.
  • Document Types: datasheet (PDF) • pinout (Diagram) • scan (Drawing) • instructions (Assembly) • article (Notes)
  • File Storage: Uploads to media/parts/documents/%Y/%m/. Auto-detects is_image, is_pdf, and formats file size.
  • WYSIWYG Articles: content = CKEditor5Field() for rich pinout tables, troubleshooting procedures, and notes.

Operational Phase Action Performed in Interface System Reaction & State Change
1. ODS Ingestion Place BoMs.ods in root and run python manage.py import_boms. Ingests 36 parts, 11 companies, 4 BOM assemblies, and links superseded revisions.
2. Category Setup Go to /categories/add/. Enter Name & Prefix (e.g. 100). Prefix stored; inherited by any child subcategories via get_prefix().
3. Part Registration Select category on /parts/add/. Leave part number blank. Auto-generates 100-1001. Computes price = price_per * qty.
4. Suffix Override Enter 1234 in Part Number input. Auto-prepends category prefix to produce 100-1234.
5. BOM Management Go to /boms/ → Click Add BOM or inspect existing assembly. Displays assembly summary, total unit cost, and component list.
6. Add Component to BOM On BOM detail page, click Add Component. Select part & quantity. Line item added; rolls up total_cost and total_parts_quantity.
7. Attach Resources On Part detail page, click Add Document / Scan. Uploads PDF/scan, renders thumbnail, and attaches to part record.
8. Document Viewing Click View on any document card. Opens dedicated high-res viewer, embedded PDF, or article body.
